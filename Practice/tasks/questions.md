# Practice Tasks

Try answering these tasks yourself before opening the sample answers.

## Shell Scripting

1. Create a script that prints your name, class, and major.
2. Create a script that asks for two numbers and prints their sum.
3. Create a script that checks whether a score is pass or fail.
4. Create a script that prints numbers 1 until 5 using a loop.
5. Create a script that uses a function to greet a user.
6. Create a script that accepts command line arguments for name and age.
7. Create a script that checks whether a given path is a file or a directory.
8. Create a script that uses `case` to show Linux command categories.

## Cron Jobs

9. Write one cron expression that runs every day at 06:00 and one that runs every Friday at 18:30.

## AWK

10. Using `students.txt`, print student names with score above or equal to 80 and calculate the average.
